## Универсальный интернет-поиск книг (v1.5)

Поиск не опирается на фиксированный список книжных сервисов: запрос уходит либо в **серверный агрегатор**, либо — если сервера нет — **прямо с телефона** через публичные SearXNG и открытые API. Найденные страницы анализируются, файлы проверяются и скачиваются в приложение.

### Два режима

| Режим | Когда используется | Что задействовано |
|---|---|---|
| **Серверный** | указан адрес сервера и он отвечает | `/api/search`, `/api/analyze`, `/api/probe`, `/api/fetch` |
| **Встроенный (device)** | сервер не задан или недоступен | публичные SearXNG из реестра `searx.space`, пользовательские инстансы, Crossref, OpenAlex, Open Library, Gutenberg (IA), локальный `/api/page` |

Встроенный режим не требует компьютера и ключей. Если публичные SearXNG временно не отвечают, поиск продолжается по открытым книжным API, а выдача честно помечается как неполная.

### Как работает

1. Пользователь вводит название или автора в строке поиска (`/search`).
2. В серверном режиме провайдеры опрашиваются параллельно с общим бюджетом времени; во встроенном — параллельно запускаются SearXNG и прямые API.
3. Список публичных SearXNG берётся из официального реестра `https://searx.space/data/instances.json`, кэшируется, проверяется по health-эндпоинту; можно добавить свои инстансы в настройках поиска.
4. Приложение анализирует найденные страницы: заголовок, авторов, описание, обложку, язык, год, ISBN и **ссылки на файлы EPUB/FB2/PDF/TXT/MOBI**.
5. Одинаковые результаты объединяются по URL, ISBN и «название + автор».
6. Каждый файл проверяется отдельным запросом: доступен, требует авторизации, только покупка, отсутствует или источник запрещает автоскачивание.
7. Для доступного файла показывается кнопка «Скачать» — с прогрессом, проверкой формата и DRM, извлечением метаданных и добавлением в библиотеку.

### Провайдеры

| Провайдер | Ключ | Что даёт |
|---|---|---|
| **SearXNG (публичные инстансы)** | без ключа | метапоиск по вебу, реестр `searx.space` + свои инстансы |
| **Google (Custom Search JSON API)** | `GOOGLE_CSE_KEY` + `GOOGLE_CSE_CX` | полноценный веб-поиск |
| **Bing Web Search** | `BING_SEARCH_KEY` | альтернативный индекс |
| **Brave Search** | `BRAVE_SEARCH_KEY` | независимый индекс |
| **Яндекс XML** | `YANDEX_XML_USER` + `YANDEX_XML_KEY` | русскоязычный веб |
| **Marginalia** | без ключа | открытый индекс независимого веба |
| **Crossref / OpenAlex** | без ключа | глобальные индексы книг (метаданные) |
| **Open Library / Gutenberg (IA)** | без ключа | открытые библиотеки с разрешёнными файлами |

Ключи задаются **только на сервере** (переменные окружения `server/serve.mjs`) и никогда не попадают в APK. Без ключей работают SearXNG, Crossref, OpenAlex, Open Library и Gutenberg.

### Экономия и устойчивость

- Реестр SearXNG кэшируется, здоровье инстансов — отдельно; запросы к публичным узлам throttled.
- Выдача SearXNG кэшируется на устройстве (`polka:searx-cache:v1`), чтобы повторный запрос не ждал сеть.
- Общий бюджет SearXNG — 10 секунд; проверяются не более двух здоровых инстансов.
- Анализ страниц и проверка файлов ограничены по времени и количеству (до 10 файлов на выдачу).
- Приватные и внутренние адреса блокируются в прокси (защита от SSRF), размер и время ответа ограничены.

### Сервер поиска

| Endpoint | Назначение |
|---|---|
| `GET /api/search/status` | список провайдеров и наличие ключей |
| `GET /api/search?q=…` | агрегированный веб-поиск |
| `GET /api/page?url=…` | загрузка HTML страницы для локального анализа (CORS/JSON) |
| `GET /api/analyze?url=…` | анализ страницы: метаданные книги и файлы |
| `GET /api/probe?url=…` | проверка доступности файла и причины отказа |
| `GET /api/fetch?url=…` | прокси-скачивание с CORS; в веб-сервере — белый список доменов |

Запуск: `pnpm serve` (или `start.bat`). В APK адрес сервера указывается на экране поиска или в профиле. Ключи задаются так:

```bash
GOOGLE_CSE_KEY=… GOOGLE_CSE_CX=… BING_SEARCH_KEY=… pnpm serve
```

### Что видит пользователь

- строку поиска с историей запросов (сохраняется на устройстве);
- фильтры по форматам и жанрам, сортировку результатов;
- карточки найденных книг с обложкой, автором, годом и языком;
- форматы с реальными размерами;
- кнопку «Скачать» для доступных файлов и **честную причину** вместо кнопки, если скачать нельзя;
- прогресс скачивания и кнопки «Читать» / «Мои книги» после добавления.

Книжные каталоги (Open Library, IA, Gutenberg, LibriVox, Google Books) остались отдельным разделом **«Каталоги»** и не являются основой интернет-поиска. Встроенный браузер (`/web`) сохранён для ручного поиска.

### Ограничения

- Публичные SearXNG нестабильны: часть инстансов закрывает JSON/CORS или rate-limit. Приложение не обходит эти ограничения, а переключается на открытые API и честно сообщает о неполноте.
- Парсинг выдачи Google/Яндекса не используется — только официальные API или SearXNG.
- DRM, CAPTCHA, авторизация и платный доступ не обходятся: показывается причина.
- Для Google/Bing/Яндекс/Brave нужен ключ на сервере; без сервера работают SearXNG, открытые индексы и локальный анализ страниц.
- MOBI определяется и скачивается, но не читается (нет конвертера).
- Если публичные инстансы перестанут принимать автоматические запросы, следующий шаг — собственный SearXNG на своём сервере (достаточно одного инстанса с JSON API).

### Компоненты

`server/search/`: `providers.mjs` (провайдеры и агрегация), `analyze.mjs` (BookPageAnalyzer + BookFileDiscovery), `probe.mjs` (DownloadLinkValidator).
`src/discovery/`: `api.ts` (клиент сервера), `engine.ts` (InternetSearchEngine + SearchResultAggregator), `searx.ts` (реестр/health/кэш SearXNG), `direct.ts` (прямые провайдеры и `/api/page`), `html.ts` (разбор HTML), `download.ts` (BookDownloadManager), `config.ts` (адрес сервера), `types.ts`.
Экран: `src/screens/InternetSearch.tsx`. Android-прокси: `android-app/src/ru/polka/books/LocalServer.java`.

### Проверки

- `pnpm check:discovery` — серверный режим: поиск с файлами, честные кнопки, скачивание и импорт, чтение, «Мои книги», каталоги (7 сценариев).
- `node e2e/discovery-direct.mjs` — встроенный режим без сервера: поиск, анализ страниц, скачивание, возврат в серверный режим (5 сценариев).
